# PTTS Microsoft 365 Web Bridge

A PTTS Linux desktop application project for opening local
Microsoft Office documents in Microsoft 365 web applications.

## Planned integrations

- Word for the web
- Excel for the web
- PowerPoint for the web
- Visio for the web

## Planned distribution

- Standalone Debian (.deb) package
- PTTS signed Linux APT repository

## Microsoft 365 prerequisites

An appropriate Microsoft 365 license and authorized
OneDrive access are required.

Corporate deployments may require approval of the
underlying Rclone Microsoft Entra application.

The application will not bypass organizational
authentication or authorization policies.

## Development status

Pre-release development. No production release is
available yet.
